# ตารางต่อขา — Hydration coaster (Node + Gateway)

บอร์ดทั้งสองตัว: **ESP32 DevKit V1 (DOIT 30 ขา)** · รูปวงจร: `wiring-node.png`, `wiring-gateway.png` (มี .svg สำหรับแก้/ซูม)

อัปเดต 10 พ.ย. 2569: เกตเวย์เปลี่ยนจาก LDR (KY-018) เป็น DHT11 (KY-015) แล้ว · แบบเดิมเก็บไว้ที่ `wiring-gateway-v1-ldr.png`

กติกาที่ใช้เลือกขา
- ขา analog ใช้ **ADC1 (GPIO32–39)** เท่านั้น เพราะ ADC2 ใช้ไม่ได้ขณะเปิด Wi-Fi/ESP-NOW
- ไม่ใช้ GPIO6–11 (แฟลช) และ GPIO0/2/5/12/15 (strapping) กับอุปกรณ์ภายนอก
- GPIO34–39 เป็น input-only และไม่มี pull-up ภายใน
- GND ทุกจุดต่อร่วมกัน

---

## 1. Node (แผ่นรองแก้ว, ใช้แบต)

### ภาคจ่ายไฟ

| จาก | ไป | หมายเหตุ |
|---|---|---|
| 18650 B+ / B− | TP4056 B+ / B− | ใช้ TP4056 รุ่นมีวงจรป้องกัน (6 ขา) |
| TP4056 OUT+ | INA219 VIN+ | INA219 ใช้ตอนทดสอบ E3 เท่านั้น ถ้าไม่วัด ให้ OUT+ ต่อตรงไปจุด VBAT |
| TP4056 OUT− | GND | |
| INA219 VIN− | **VBAT** (3.0–4.2 V) | จุดแยกไฟ |
| VBAT | LDO 3.3 V VIN | AP2112K-3.3 หรือ ME6211 (≥500 mA, dropout ต่ำ) — **ห้ามใช้ AMS1117** |
| LDO VOUT | **+3V3** → ESP32 ขา **3V3** | ใส่ C 10 µF + 100 µF คร่อม 3V3–GND |
| VBAT | MT3608 VIN+ | ตั้ง trimmer ให้ได้ **5.0 V** ก่อนต่อโหลด |
| MT3608 VOUT+ | **+5V** → HC-SR04 VCC เท่านั้น | |
| ESP32 VIN | — | **ไม่ต่อ** |

### สัญญาณ

| โมดูล | ขาโมดูล | ESP32 (ป้ายบนบอร์ด / GPIO) | ระดับแรงดัน / หมายเหตุ |
|---|---|---|---|
| HX711 | VCC (และ VDD ถ้ามี) | 3V3 | เลี้ยง 3.3 V → สัญญาณ 3.3 V ต่อตรงได้ |
| HX711 | GND | GND | |
| HX711 | DT (DOUT) | **D19 / GPIO19** | input |
| HX711 | SCK | **D18 / GPIO18** | output · ค้าง HIGH >60 µs = power-down ก่อน deep sleep |
| Load cell → HX711 | แดง / ดำ / ขาว / เขียว | E+ / E− / A− / A+ | ถ้าน้ำหนักติดลบ สลับ A+ กับ A− |
| HC-SR04 | VCC | +5V (MT3608) | |
| HC-SR04 | GND | GND | |
| HC-SR04 | Trig | **D25 / GPIO25** | 3.3 V จาก ESP32 สั่ง trig ได้ |
| HC-SR04 | Echo | **D26 / GPIO26** ผ่านตัวแบ่ง | Echo = **5 V** → 1 kΩ อนุกรม, 2 kΩ ลง GND (ได้ ≈3.3 V) |
| แบ่งแรงดันแบต | VBAT–100k–จุดกลาง–100k–GND | **D34 / GPIO34** | batt_mv = ADC_mV × 2 · ใส่ 100 nF ที่จุดกลาง |
| INA219 | VCC / GND | 3V3 / GND | ทดสอบ E3 |
| INA219 | SDA / SCL | **D21 / GPIO21**, **D22 / GPIO22** | I²C ที่อยู่ 0x40 (โมดูลมี pull-up แล้ว) |

> ถ้าอัลตราโซนิกที่ยืมมาเป็นรุ่น **HC-SR04P / RCWL-1601 (3.3 V)**: ต่อ VCC เข้า 3V3 แล้วต่อ Echo ตรงเข้า GPIO26 ได้ ไม่ต้องใช้ MT3608 และตัวต้านทาน 1k/2k

## 2. Gateway (กล่องป้าย, ไฟ USB)

### ภาคจ่ายไฟ

| จาก | ไป | หมายเหตุ |
|---|---|---|
| อะแดปเตอร์ USB 5 V ≥1 A | ช่อง USB ของ ESP32 | ขา **VIN** = +5V ใช้จ่ายให้ PIR และเซอร์โว |
| ESP32 ขา **3V3** | +3V3 | จ่าย KY-038, DHT11 |

### สัญญาณ

| โมดูล | ขาโมดูล | ESP32 (ป้ายบนบอร์ด / GPIO) | ระดับแรงดัน / หมายเหตุ |
|---|---|---|---|
| เสียง KY-038 | + / G | 3V3 / GND | **ห้ามเลี้ยง 5 V** |
| เสียง KY-038 | AO | **D35 / GPIO35** (ADC1_CH7) | analog มีไบแอสครึ่งไฟ → วัด peak-to-peak ช่วง ~50 ms |
| เสียง KY-038 | DO | **D32 / GPIO32** | digital ตั้ง threshold ด้วย trimmer (ใช้เป็น interrupt สำรองได้) |
| PIR HC-SR501 | VCC / GND | +5V (VIN) / GND | ไฟเลี้ยง 4.5–20 V |
| PIR HC-SR501 | OUT | **D27 / GPIO27** | OUT = 3.3 V ต่อตรงได้ · interrupt ขาขึ้น (E2) · jumper = H |
| ปุ่มหยุดฉุกเฉิน | ขา 1 / ขา 2 | **D33 / GPIO33** / GND | INPUT_PULLUP + interrupt ขาลง |
| Servo SG90 | สายส้ม (สัญญาณ) | **D18 / GPIO18** | PWM 50 Hz (LEDC) · สัญญาณ 3.3 V ใช้ได้ |
| Servo SG90 | สายแดง / น้ำตาล | +5V (VIN) / GND | C 470–1000 µF/10 V คร่อมชิดขั้วเซอร์โว |
| DHT11 KY-015 | + / − | 3V3 / GND | อุณหภูมิ/ความชื้นห้อง → feature ของ AI (ห้องร้อน = ต้องการน้ำมากขึ้น) |
| DHT11 KY-015 | S | **D14 / GPIO14** | digital 1-wire · โมดูลมี pull-up 10k ในตัว · อ่านทุก 5–10 วินาที |
| LED บนบอร์ด | — | D2 / GPIO2 | ใช้แสดงสถานะ ไม่ต้องต่อเพิ่ม |

> ถ้าบอร์ดรีเซ็ตตอนเซอร์โวหมุน (brownout): แยกไฟ 5 V ให้เซอร์โวจากอีกแหล่ง แต่ต้องต่อ GND ร่วมกับ ESP32
