# กรณีใช้งานจริง และระบบทำอะไร (gateway)

ค่าทั้งหมดอยู่บนสุดของ `gateway/gateway.ino` หัวข้อ "กติกาสำหรับใช้งานจริง"
พิมพ์ `w` ใน Serial Monitor เพื่อดูว่าตอนนี้ AI ได้ค่าเท่าไร และถ้าป้ายไม่ยก ติดเงื่อนไขข้อไหน

## ป้ายยกเมื่อ
ผ่านเงื่อนไข "ห้ามยก" ทุกข้อด้านล่าง **และ** ข้อใดข้อหนึ่งนี้
1. AI ให้ความเสี่ยง p ≥ 0.70
2. ไม่ได้ดื่มมานานเกิน `MAX_NO_DRINK_MIN` = 90 นาที (กฎตายตัว ไม่ต้องรอ AI)

## ป้ายลงเมื่อ
- ดื่ม (น้ำหนักลด ≥ 15 g แล้ววางนิ่ง) → ลงทันที แล้วพักไว้ 15 นาที
- AI ให้ p ≤ 0.62 และป้ายยกมาแล้วอย่างน้อย 1 นาที และยังไม่เกิน 90 นาทีนับจากดื่มครั้งล่าสุด
- เข้าช่วงเวลาเงียบ (22:00–07:00)
- สั่งเอง `n`

## กรณีจริง

| กรณี | ระบบทำอะไร | ค่าที่ปรับได้ |
|---|---|---|
| เพิ่งเปิดเครื่อง / อัปโค้ดใหม่ | ห้ามยก 60 วิแรก และจนกว่าจะได้ข้อมูลจาก node | `AI_WARMUP_MS` |
| ลุกไปจากโต๊ะ (PIR ไม่ขยับ 5 นาที และ ultrasonic ไม่เห็นคน) | ไม่ยกป้ายใหม่ เพราะไม่มีคนเห็น ถ้าป้ายยกค้างอยู่แล้ว จะยกค้างไว้เตือนตอนกลับมา และยังส่ง LINE ได้ | `REQUIRE_PRESENT`, `PIR_WINDOW_MS`, `PRESENCE_CM` |
| ยกแก้วออกจากแท่น (กำลังดื่ม) | ห้ามยกป้าย 3 นาที ถ้าเกินนั้น (เอาแก้วไปเติม/ลืมไว้) กลับมาใช้กติกาปกติ | `CUP_AWAY_GRACE_MS` |
| node ดับ / แบตหมด / กดปุ่ม sleep / อยู่ไกล | node เงียบเกิน 60 วิ → ไม่รู้ว่าดื่มหรือยัง จึงไม่ยกป้ายใหม่ และไม่ใช้ค่า ultrasonic เก่ามาบอกว่ามีคน | `NODE_STALE_MS` |
| ข้อมูลที่ node ค้างคิวไว้ส่งย้อนหลัง | ใช้นับการดื่มตามปกติ แต่ไม่ใช้บอกว่าตอนนี้มีคนไหม | |
| gateway ไฟดับ / รีบูต | ยอดดื่มวันนี้และเวลาดื่มล่าสุดเก็บใน flash (NVS) คืนค่าเมื่อได้เวลา NTP | |
| ข้ามวัน | รีเซ็ตยอดวันนี้ตอนเที่ยงคืน | |
| กลางคืน | 22:00–07:00 ไม่ยกป้าย ไม่ส่ง LINE และลดป้ายที่ยกค้าง (ไม่ใช้ตอน `DEMO_SPEED` ≠ 1) | `QUIET_START_H`, `QUIET_END_H` (ตั้งเท่ากัน = ปิด) |
| DHT11 อ่านเพี้ยน / เสียงดังกระแทก | ตัดค่าที่ส่งเข้า AI ไว้ในช่วงเฉลี่ย ± 3 SD ของข้อมูลเทรน ค่าเพี้ยนดันป้ายเกินจริงไม่ได้ | |
| ป้ายยกลงสลับไปมา | เกณฑ์ยก 0.70 / ลด 0.62 ห่างกัน และป้ายต้องค้างอย่างน้อย 1 นาทีก่อน AI เปลี่ยนอีก (การดื่มไม่ต้องรอ) | `AI_P_UP`, `AI_P_DOWN`, `MIN_DWELL_MS` |
| ป้ายยกแล้วไม่ดื่ม | ยกค้าง 10 นาที → LINE แล้วส่งซ้ำได้ทุก 30 นาที | `LINE_AFTER_MIN`, `LINE_COOLDOWN_MS` |
| กดปุ่มหยุดฉุกเฉิน | เซอร์โวหยุด ป้ายไม่เปลี่ยนจนกว่าพิมพ์ `c` | |

## ตอนถ่ายวิดีโอ
- ตั้ง `DEMO_SPEED 60` → 90 นาที = 90 วิ, พักหลังดื่ม 15 นาที = 15 วิ, ช่วงเวลาเงียบปิดเอง
- ถ้า PIR/ultrasonic ไม่ค่อยจับคน ป้ายจะไม่ยก (`w` จะบอก "ไม่มีคนหน้าโต๊ะ") ให้โบกมือหน้า PIR หรือตั้ง `REQUIRE_PRESENT = false`
